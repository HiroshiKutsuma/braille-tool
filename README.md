# 点字ツール（試作版）

ひらがなの文章を点字に変換し、BASE形式（*.BSE）の点字ファイルとして保存できるWebアプリです。BSEファイルを開いて点字を表示することもできます。

**使ってみる：** https://hiroshikutsuma.github.io/braille-tool/

## できること

- ひらがなの文章を点字に変換して表示する
- BSEファイルとして保存する／テキストとして保存する
- BSEファイル・テキストファイルを開く
- 凹式（書く面）・凸式（読む面）の表示を切り替える
- 記号（句読点、かっこ、つなぎ符、線類、英文記号など）を挿入する
- 英字の書き方を外字符・外国語引用符から選ぶ
- 数字の位取り、第一つなぎ符の自動挿入

## 使い方

1. 上のリンクをパソコンやスマホのブラウザで開きます。
2. 入力欄にひらがなで文章を入れ、「変換」を押します。
3. 点字が表示されたら、「BSEを保存」でファイルとして保存できます。

## ご注意

- **試作版です。** 変換結果は必ず校正してください。
- 個人が作った非公式のツールです。T・エディタやBASEの開発者とは関係ありません。
- BASE形式への対応は、実際のファイルをもとに独自に調べたものです。すべてのファイルで正しく動くことは保証できません。
- 入力した文章やファイルはブラウザの中だけで処理し、どこにも送信しません。

## 不具合を見つけたら

正しく変換されなかった文章や、うまく開けなかったBSEファイルの例を教えてもらえると、改良に役立ちます。
